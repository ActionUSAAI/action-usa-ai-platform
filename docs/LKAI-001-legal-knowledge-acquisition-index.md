## Control de Integridad (por fuente)

Para cada fuente: fecha de inicio, fecha de finalización, versión oficial utilizada, URL oficial, responsable de extracción, responsable de verificación, estado (`Not Started` / `In Progress` / `Completed` / `Superseded`).

## Registro de Cambios

Toda modificación del corpus registra: fuente afectada, motivo, nueva versión oficial, registros sustituidos, fecha.

## Regla de Separación Adquisición / Verificación

Ninguna sesión combina adquisición y verificación. Adquisición: extracción siguiendo LKAS-001. Verificación: comparación del corpus ya extraído contra la fuente oficial, en sesión separada, para detectar omisiones, errores de transcripción, o problemas de trazabilidad.

## Criterio de Cierre por Fuente

Una fuente se marca `Completed` únicamente cuando: todas sus unidades oficialmente delimitadas fueron extraídas conforme a LKAS-001; la extracción fue verificada (en sesión separada); existe trazabilidad completa; no quedan unidades pendientes.
